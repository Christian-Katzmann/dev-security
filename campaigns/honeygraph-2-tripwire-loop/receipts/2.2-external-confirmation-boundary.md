# Receipt — Step 2.2: Confront the local-trigger gap honestly

## What I decided

Picked **Option B: "DëvSec mints and binds; you deploy and point it at your
collector."** A reachable trigger collector is **out of scope** for a local-first
tool to *host* — hosting one means a non-loopback listener / a network service,
which breaks the local-first promise, the unattended-run firewall contract, and
the display-only External-Surface MVP posture. Instead DëvSec gained a
**deployed-decoy placement mode** that bakes an operator-supplied reachable
collector URL into the decoy as config — it never deploys, listens, or contacts
anything. Full reasoning + the rejected Option A in
`notes/2.2-external-confirmation-boundary.md`.

## What I built (smallest honest piece — no live deploy, no listener)

- `honey_keys.build_decoy_snippets(..., trigger_base_url=None)` — when set, the
  decoy's `trigger_url` + `open_url` are built from the operator collector;
  otherwise unchanged (loopback). Local mode is byte-for-byte identical to before.
- `honey_keys.validate_collector_base_url(value)` — accepts only an absolute
  `http(s)` URL with a host, normalizes (strips trailing slash). **Never contacts
  it** — pure config validation, no liveness probe.
- `POST /api/honey/keys` — new `placementMode` (`local` default | `deployed`) and
  `triggerBaseUrl`. Deployed mode requires a valid collector URL (400 otherwise),
  threads it into minting + persistence, and returns `placement_mode` +
  `trigger_base_url` + an honest `placement_notice`.
- `honey_keys.trigger_base_url` column — additive + idempotent in
  `_ensure_columns` (mirrors `asset_node_id`); threaded through
  `storage.create_honey_key`. The store now records which keys are deployed
  decoys and what collector they target.
- `docs/honey-keys.md` — new "Deployed Decoys & the External Boundary" section
  stating plainly: DëvSec mints + binds; the operator deploys + hosts; a
  127.0.0.1 trip is not a remote attacker.

Everything DëvSec runs still binds `127.0.0.1`. The collector URL is text in the
decoy + a DB row — never a host DëvSec connects to.
