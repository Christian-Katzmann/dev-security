# Receipt — Step 1.2: Pre-execution digest check for managed scanners

**Outcome:** Managed scanner binaries are re-hashed immediately before launch and refused on mismatch.

## Changes

- [managed_tools.py](../../../src/security_observatory/managed_tools.py): `install_managed_tool_files` records the extracted binary's sha256 at `metadata.binary_sha256`; new `resolve_managed_scanner_binary` returns `none`/`ok`/`tampered`; `manifest_record_from_db_record` now carries `metadata` so the integrity baseline survives the manifest-fallback path.
- [scanners.py](../../../src/security_observatory/scanners.py): `run_scanner` uses the resolver. A `tampered` result yields a `skipped`/error `ScannerStatus` and returns early — no PATH fallback. Removed the now-dead `_verified_managed_binary_for_scanner`.

## Acceptance criteria

- [x] Managed execution checks recorded sha256 against the on-disk executable before subprocess launch.
- [x] A mismatch produces a visible skipped/error status, not a silent PATH fallback — `test_run_scanner_refuses_tampered_managed_binary` (PATH copy present, still refused, `exit_code is None`).
- [x] User-owned PATH scanners keep current behavior; nothing is deleted/relinked/modified — resolver returns `none` for non-managed/unverified.
- [x] Tests cover passing managed binary (`..._runs_managed_binary_when_digest_matches`), mismatched (`..._refuses_tampered_managed_binary`), and missing baseline (existing `..._uses_verified_managed_gitleaks_when_path_is_empty`).
- [x] Fast import check + pytest subset pass.

## Migration decision (open question)

Legacy installs created before digest recording have no baseline. **Chosen behavior: allowed but flagged** (`state=ok` with a "no integrity baseline recorded; reinstall to capture one" note) rather than blocking a previously trusted install on upgrade. New installs always record a baseline, so they get full enforcement. The integrity gate hashes the *binary*; note the existing `checksum` field stores the *archive* digest, which is why a new `binary_sha256` was needed.
