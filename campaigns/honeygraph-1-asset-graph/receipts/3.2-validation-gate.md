# Step 3.2 — Prove the re-rank is truer (the trust-gate)

**Phase 3 — the honesty test.** On real stored scan data + a real, freshly-built
dependency graph, compared the severity-ordered top-10 against the
consequence-ordered top-10 and made the GO/NO-GO call that gates Campaign 2.

## Verdict: **GO (scoped)**

The graph does not mis-rank. The consequence re-rank is demonstrably truer on real
data, is purely additive, and never buries a higher-severity finding. Campaign 2
may proceed — but its honest promise must be scoped to **dependency reachability**;
the novel IaC blast-radius-to-a-datastore signal never fired on any real repo (no
Terraform exists in `~/Dev`). Full reasoning + conditions in
`campaigns/honeygraph-1-asset-graph/notes/consequence-vs-severity.md`.

## What I did

- Discovered the local DB predates the campaign: no `asset_nodes`/`asset_edges`,
  no SBOM components, and the default scan profile never generates SBOM/IaC — so
  existing history carries no graph and can't show consequence directly.
- Built the comparison from **real findings** (stored `normalized-report.json`) +
  a **real dependency graph** (Syft `cyclonedx-json`, parsed by production
  `load_sbom_components` / `load_sbom_dependency_edges`), run through the **exact**
  ranking code `scan_repo` runs (`build_security_cases` → `correlate_dependency_findings`
  → `derive_asset_nodes` → `mark_crown_jewels` → `attach_consequences` →
  `apply_consequence_priority`). No toy fixtures, no reimplementation.

## Evidence (two real repos, reproducible)

- **Dashboard-Studio** (npm, 148 findings, 1319 comps, 1491 edges; crown jewels
  `express` + `@libsql/client`): 4 medium vulns — `qs`, `path-to-regexp`×2, `ws`,
  all HTTP/WS request-path parsers — promoted `verify→fix_now`, jumping ranks
  130–146 → 5–8, landing above non-reachable highs; ~50 look-alike medium vulns
  that reach nothing stayed buried. All 5 criticals untouched at ranks 1–5.
- **gitslip** (pnpm, 197 findings; crown jewel `wrangler`): 14 vulns promoted,
  landing right after the 16 criticals — never displacing them. Reproduces cleanly.
- **Conservatism check:** crowning `@anthropic-ai/sdk` on Dashboard-Studio promotes
  **0** (vulns aren't in its subtree) — the signal discriminates, it's not a stamp.

## Honest limits (recorded in the note)

- **Novel IaC signal never fired.** Zero `.tf` under `~/Dev`; datastore classifier
  is Terraform-only ⇒ zero datastore/resource nodes, zero IaC edges. Only
  dependency reachability (table-stakes) was provable.
- **Zero weak edges on real data.** Every Syft `depends_on` edge is `strong`, so
  every promotion was strong-path. The "no auto-promote on a weak edge" rule and
  weakest-link machinery are proven only by unit tests, not this run.
- **Component crown jewels are keyed by `component_fingerprint`** (24-hex) — not
  human-authorable; needs a "mark this package" affordance.
- **Crown-jewel choice drives the result** — gitslip's most-connected nodes are
  dev/test tooling; a naive label would mis-promote build-time vulns.
