# 4.1 Add VEX Decisions and Safe Suppression

## What changed

- Case decisions now carry VEX-style dependency status: `affected`, `not_affected`, `fixed`, or `under_investigation`.
- Existing decisions migrate safely with default VEX status derived from the old decision status.
- Dependency suppressions require a human-readable justification.
- Suppression matching can carry forward to future scans only when the repository, advisory ID, and package identity match.
- Report assembly now separates active findings/cases from suppressed findings/cases while keeping suppressed evidence inspectable.
- Dashboard payloads expose active counts, raw counts, suppressed counts, and suppression reasons.
