## Behavior Notes

- First scans with an SBOM do not label every package as added; they explain that there is no previous scan to compare.
- Latest scans without SBOM data do not label every previous package as removed; they show a no-SBOM state.
- Version direction is inferred only when the version text has comparable numeric structure. Otherwise, the change is reported as version-changed.
- Dashboard package totals and change-type counts now come from persisted SBOM history, not scanner finding counts.
