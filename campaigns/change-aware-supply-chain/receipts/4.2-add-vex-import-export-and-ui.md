# 4.2 Add VEX Import/Export and UI Visibility

## What changed

- Added local VEX-compatible export with `security-scan vex-export`.
- Added local VEX-compatible import with `security-scan vex-import`.
- Exported dependency decisions use an OpenVEX-like `statements` document for `affected` and `not_affected` decisions.
- Import accepts the local OpenVEX-like subset and a small CycloneDX-like vulnerability subset.
- Imported matching dependency decisions are saved as normal case decisions, so they apply to future scans through the existing suppression matcher.
- Unsupported VEX fields are ignored with clear import notes; unsupported statuses or incomplete suppressions are skipped instead of crashing.
- The dashboard now keeps active findings in the main "What Needs Attention" path and shows suppressed findings in a separate audit section.
- Suppressed cards show concise suppression status, VEX status, reason, and update date labels.
- Documented the supported VEX subset in `docs/false-positives.md`.
