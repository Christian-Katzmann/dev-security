# Receipt: 5.1 Add Optional Platform Posture Drift

## What Changed

- Added `security-scan --platform-posture` as an explicit connected-mode profile.
- Added optional legitify scanner plumbing without adding it to default, quick, or full local scans.
- Normalized legitify failures into the `platform-posture` category.
- Saved sanitized platform posture snapshots in SQLite.
- Added drift detection for important regressions, including default branch protection becoming disabled and workflow token permissions widening.
- Integrated platform posture findings into the Infrastructure dashboard view.
- Documented token requirements and the privacy boundary.

## Privacy Boundary

- Tokens are read from environment variables and are not saved in command arguments.
- Scanner status command previews use a placeholder repository target.
- Posture snapshots keep policy state and hashed resource references, not raw SCM entity ids, entity names, raw `aux` metadata, or full platform URLs.
- Missing legitify, credentials, scopes, or repo target saves the platform scan as skipped/partial and leaves the rest of the run usable.
