## Executive Finding

<!-- AGENT: Write the cross-cluster Executive Finding. Read all three clusters' Executive Findings, then write ONE story across all of them — not three side-by-side. The merged finding identifies the single biggest pattern visible only when reading clusters together. Cite global S-IDs. -->

DëvSec has a strong, security-critical **core** wrapped in a thin, leaky **ring**, and almost every finding in this campaign is a version of that one shape. The core is genuinely excellent and test-pinned: the MCP/AI write boundary refuses to auto-suppress high/critical findings even under a prompt-injected payload, the clean-room fix reviewer is structurally fenced, scans are offline by default, secrets are redacted before storage, and the scanner pipeline degrades honestly. The damage all lives in the ring around that core — the dashboard HTTP layer, the React UI, the TypeScript type floor, the `.adx` agent docs, the changelog. Both non-negotiable trust breaches are exactly this pattern: the *proven* suppression gate is walked around through a CSRF-unprotected dashboard (S-001), and the *proven* offline guarantee is broken by a Google Fonts CDN call in shipped CSS (S-002) — a sound invariant living somewhere that does not enforce it. The largest *product* opportunity is the same shape inverted: powerful local-first machinery is already built but **dark** in the UI — the hands-off code-fix flow (S-043), scan history and arbitrary scan-diff (S-039), the posture-trend helper (S-042), and a real case lifecycle (S-035). This campaign is not a rescue; it is *finishing the ring around a strong core*, and the highest-leverage repairs are structural and UI seams that each lift several lenses at once.

## Cross-Cutting Patterns

2. **Built-but-dark: a capability/visibility inversion.** DëvSec has shipped powerful, trust-safe, local-first capability that never reaches the user: S-043 (code-fix flow is MCP-only), S-039 (scan-history has no UI consumer; arbitrary scan-diff is built but unreachable), S-042 (posture-trend helper is dead code), S-035 (no in-progress/verifying lifecycle state), S-044 (dead filter chips). 3. **Sound invariant, soft enforcement.** Discipline that exists by convention but isn't mechanically guarded, so it can silently erode: S-021 (TS strict off → the zero-`any` discipline is decorative), S-024 + S-025 (no-dropped-findings and no-egress proven per-function but with no count-conservation or repo-wide sentinel), S-040 + S-041 + S-047 (DESIGN.md declares an a11y floor with no focus ring, no modal focus-trap, and no a11y tests), S-023 (one JSON decode guarded, three not).
