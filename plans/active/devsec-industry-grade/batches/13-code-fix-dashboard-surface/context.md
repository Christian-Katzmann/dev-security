# Batch: 13-code-fix-dashboard-surface

## Purpose
DëvSec's strongest realization of the Brief's safe-AI-write ideal — the hands-off code-fix flow (`propose_fix → clean_room_review_packet → record_clean_room_review → land_fix`) — is fully built, fenced (the clean-room reviewer sees only the diff and invariants, never the finding text), and test-pinned, yet it is reachable **only** through the MCP rw adapter: it has no dashboard surface and no entry in the README's "real vs not yet" table. This batch (S-043) makes that hidden superpower honest and reachable: either by adding a dashboard proposals surface (list → diff → clean-room verdict → land decision) mirroring the existing rotation flow, or by explicitly documenting it as MCP-only in the "real vs not yet" table. The single shared fix surface is the gap between the built code-fix subsystem (`fix_proposals.py` + its MCP tools) and what a dashboard-only user can see.
