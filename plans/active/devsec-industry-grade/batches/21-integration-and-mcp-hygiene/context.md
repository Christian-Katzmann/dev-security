# Batch: 21-integration-and-mcp-hygiene

## Purpose
This is the closing hardening batch: it locks the trust-airtight invariants on DëvSec's integration and MCP/AI surfaces — the surfaces that are already **Green or near-Green** — so they cannot silently regress as the catalog, the AI write path, and the long-running server grow. It also reconciles one doc-vs-code drift (KEV/EPSS) so a dead-but-documented network path can never become silent egress. Concretely: **S-008** makes the CISA KEV / EPSS promise and code agree; **S-011** locks the setup-probe `shell=True` invariant and records the deliberate no-retry decision; **S-009** hardens the MCP path-leak test from `startswith` to substring; **S-012** closes the last sliver of prompt-injection surface and removes a shown-but-ignored field; **S-013** adds a reset full-cleanup test (and optional cache cleanup); **S-014** prunes terminal `_JOBS` entries after a TTL. The shared fix surface is **regression-guard tests plus narrow, low-risk source touches across the integration / MCP / reset / job-tracking code** — turning proven-today properties into suite-enforced invariants, not building new features.
