# Batch: 18-type-floor-and-contracts

## Purpose
DëvSec's case data is the one trust-critical shape with no DB-level column typing — its whole contract rests on the `SecurityCase` dataclass plus JSON round-tripping, and the React side that consumes it ships without TypeScript `strict`, so its careful `?`/`| null` annotations are decorative at compile time. This batch fixes three super-list items on that single type-floor-and-case-contract surface: **S-021** turns on TS strict so the existing zero-`any` discipline becomes enforced (the safety net that makes S-022 safe), **S-022** tightens the two case-write contracts — trim the drifted frontend `SecurityCase` type to the real wire shape and narrow `save_scan`'s `cases` parameter so redaction/validation can never be bypassed, and **S-026** adopts `PRAGMA user_version` so the schema contract is actually versioned and traceable for recovery instead of inferred from a string sentinel. Together they convert "disciplined by convention" into "enforced by the compiler and the schema."
