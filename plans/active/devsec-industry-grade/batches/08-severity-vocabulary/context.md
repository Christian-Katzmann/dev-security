# Batch: 08-severity-vocabulary

## Purpose
DëvSec exists so a user never has to translate the same security word twice, but that promise leaks at the naming boundary. This batch unifies the severity vocabulary so the dashboard, CLI, and MCP agent never disagree about one case's severity (**S-019**), and removes the residual domain-language drift — most importantly the confident falsehood where an `unknown` case confidence is silently presented as `medium` (**S-032**). Both items are owned by the same domain-language-health lens and share one fix surface: the cross-surface vocabulary layer spanning `model.py`, the React dashboard (`App.tsx`, `dashboardData.ts`), the MCP/CLI agent persona, and the `docs/` glossary. Fixing them makes the trust signals the product shows match the ones it speaks.

## Source Evidence
