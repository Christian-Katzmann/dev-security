# Batch: 12-surface-scan-history-trends

## Purpose
DëvSec already computes a full per-scan posture history and arbitrary scan-to-scan comparison data locally, but that machinery is **dark** in the dashboard — the user sees only a thin 7-bar week proxy and a "since last scan" delta, never the real history series or a free choice of which two scans to compare. This batch finishes the ring around that strong, tested substrate: it surfaces the scan-history / posture-over-time trend the Brief calls a local-first superpower (**S-039**, **S-042**) and lets the user diff any two scans, not just the last pair (**S-039**). Both items share one fix surface — the dashboard's history/trend rendering layer (`dashboard-ui/src/App.tsx`, `dashboard-ui/src/dashboardData.ts`, and the `SinceLastScanPanel` / Overview surface) sitting on the already-built `summary.history` + per-repo delta payload — so wiring the dead `trendValues` helper and the arbitrary base/head compare is one coherent change, not two.
