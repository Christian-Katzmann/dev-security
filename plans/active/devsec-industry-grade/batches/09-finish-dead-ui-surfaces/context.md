# Batch: 09-finish-dead-ui-surfaces

## Purpose
The DëvSec dashboard is mostly crafted, but four surfaces are dead or half-built — controls that look interactive and do nothing, a false keyboard hint, an undifferentiated scan-failure error, and a whole orphaned second case UI that misleads readers about which act path is real. This batch finishes (or honestly retires) each one so the product never presents a half-state as whole: delete the orphaned parallel case UI (**S-036**), make ⌘K real or remove the false hint (**S-037**), differentiate scan-failure feedback into crafted error states (**S-038**), and wire or retire the dead Activity filter chips (**S-044**). All four share one fix surface — the React dashboard (`dashboard-ui/src/`, primarily `App.tsx` plus the orphaned `components/` trio) — and together they close the "janky / dead-end UX" failure-mode for the dashboard's finished-feel bar.
